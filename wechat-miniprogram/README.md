# 电工运维助手 PowerOps 微信小程序

## 当前版本
- 电缆截面初步推荐（载流量与电压降估算）
- 电缆电阻计算
- 线路损耗功率、电量和电费估算
- 本地计算历史（微信本地缓存，离线可查看）
- 制作人：杨和龙

## 导入微信开发者工具
1. 下载本仓库代码，或在 GitHub 切换到 `wechat-miniprogram` 分支。
2. 在微信开发者工具中选择“导入项目”。
3. 项目目录选择本文件夹 `wechat-miniprogram`。
4. 当前 project.config.json 使用体验用的 `touristappid`。正式提交前请替换为你自己的小程序 AppID。
5. 编译后在模拟器和真机检查输入、计算结果及历史记录。

## 说明
本工具用于现场初步估算，不替代设计计算、厂家载流量数据和现行标准校核。当前没有云端账号体系，历史记录保存在当前微信客户端本地。
